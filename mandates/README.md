# mandates: Chains That Only Narrow

Status: `draft` (decision 0003).

## 1. Concept

A mandate empowers a holder within kinds of act, matters, an allowance per resource, a term and a slice per resource. A chain stands when its root can answer, each link was issued by its parent's holder, each narrows its parent and none is revoked. Charged along the chain, every ceiling bounds the use beneath it (Proposition 2); a remote verifier lets at most min(B, σ) through after a revocation (Proposition 3).

## 2. Content

`Mandate`, `Registry`, `chain`, `faults`, `root_principal`, `Envelopes`, `control_faults`, `exposure`.

## 3. Checks

400 random chains, 200 random trees of envelopes, 2,000 cases of late revocation, the faults of control.
