# constitutions: Constitutions as Data

Status: `draft` (decision 0003).

## 1. Concept

The written form `noetarium.constitution/1` read exactly, Ostrom's seven kinds of rules with bodies, scenes, conversions, claims, custody, preserved properties, amendment and records; admission by nine conditions of form; the report of recognised against executable powers.

## 2. Content

`Constitution`, `read`, `admission`, `Fault`, `recognised`, `mentions`, `permits`, `forbids`, `may_hold`, `wait`, `powers`.

## 3. Checks

An illustrative constitution admitted; a breach of each condition found; a reserve declared; text that is not JSON refused.
